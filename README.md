# discord-activity

You'll want to set these environment variables before running the program:
- `DISCORD_APP_ID`: An application ID. Visit the [Discord Developer Portal](https://discord.com/developers/applications) to create or manage an application.
- `DISCORD_ACTIVITY_IMAGE` (optional): The name of a rich presence art asset.
- `DISCORD_ACTIVITY_IMAGE_TEXT` (optional): The text to show when hovering over the activity image.
- `DISCORD_ACTIVITY_DETAILS` (optional): The text to show as the current activity.
